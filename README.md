# fikovnik.net

[Zola](https://www.getzola.org/) + the [serene](https://github.com/isunjn/serene) theme
(submodule in `themes/serene`). Content is Markdown under `content/`, files served as-is
under `static/`.

```sh
git submodule update --init   # if cloned without --recurse-submodules
make serve                    # http://localhost:1111
make build                    # into ./public
make check                    # content and links
make publications             # regenerate the publications page from BibTeX
```

Docker only — Zola runs in a container.

## Publications

`content/publications/_index.md` is generated by `make publications` from
`static/publications/publications.bib`; edit the bib, not the page. The intro text lives in
`HEADER` in `scripts/bib2md.py`. A `[pdf]` link appears when `static/publications/<key>.pdf`
exists.

## Theme changes

The theme is used as-is except for `templates/macros/prose.html` (menu next to the back
link), `templates/_custom_css.html` (colors, layout fixes) and
`templates/shortcodes/gallery.html`. Note the theme loads `_custom_css.html` *before*
`main.css`, so overrides there need to out-specify the theme.

## Deploy

Push to `main`: `.github/workflows/deploy.yml` builds and publishes to GitHub Pages
(Settings → Pages → Source = GitHub Actions). `static/CNAME` holds the domain.
